# Mole FM public media

Verified original music-video assets supporting the Mole FM 94.5 website and independent TV player at https://molefm.com/#/tv/originals. This repository contains public release metadata and media only; website source, private receipts and credentials are excluded.

Music and artwork are AI-assisted. Mole FM retains the rights recorded for its original lyrics, selected Suno commercial-use sources and artwork. No Creative Commons, public-domain or software licence is granted for the media. Contact Mole FM through https://molefm.com for reuse permission.

Release assets use SHA-256 filenames. The player accepts only matching approved source, rights and media-integrity evidence. Availability depends on hosting; this repository does not promise uninterrupted broadcasting.
